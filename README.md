## 📌 Project Description
This project is a machine learning-based travel analytics system.
It predicts travel cost using user inputs and provides insights through an interactive dashboard built with Streamlit.

## 🛠️ Tech Stack
- Python
- Streamlit
- Machine Learning
- Pandas, NumPy

## 📊 Features
- Travel cost prediction
- Interactive dashboard
- Smart insights
- Real-time user input processing
